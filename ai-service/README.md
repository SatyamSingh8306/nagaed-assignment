# FastAPI username service

Python 3.12 is the Docker/runtime target. From this directory:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
# Set GROQ_API_KEY in .env for live suggestions.
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Open http://localhost:8000/docs. Through Compose, open http://localhost:8080/docs.
Swagger assets load from the default FastAPI CDN and need internet access.

```powershell
python -m unittest discover -s tests -v
# Optional development formatter/linter:
python -m pip install ruff
python -m ruff check .
python -m ruff format --check .
```

`POST /api/suggest-username` accepts `{"interests":["music","science"]}` and
returns `{"suggestions":["MusicFox","ScienceTrail","RhythmOak"]}`. Those names
illustrate the response shape; live results are generated by Groq.

Structure:

- `app/api`: route registration, health and username endpoints.
- `app/core`: validated .env settings, safe logging, consistent exception handlers.
- `app/services`: username business logic, overall timeout and error translation.
- `app/providers`: provider interface and LangChain ChatGroq implementation.
- `app/prompts`: system instructions treating interests as untrusted data.
- `app/schemas`: request/response models, including three distinct valid usernames.
- `app/utils/retries.py`: one retry for transient Groq failures; no retries for bad
  credentials or malformed output. SDK retries are disabled to avoid stacking them.

The LangChain provider uses JSON mode and validates the result with Pydantic.
Each attempt has an eight-second timeout and the whole operation is capped at
19 seconds. Missing key: 503; invalid interests: 422; provider/output failure: 502.
The liveness health check does not consume paid API requests or require a key.
The HTTP client is created once per process and reused through a cached service.
No interests, model responses or secrets are written to application logs.

Only Groq is implemented because the assignment requires Groq. The provider
interface allows another provider to be added without changing the route. The
Nginx gateway limits suggestions to 6 requests/minute/IP with a burst of 3; the
AI port should stay private. Tests use mocked providers and never spend API quota.

Reference: https://reference.langchain.com/python/langchain-groq/chat_models/ChatGroq/with_structured_output
